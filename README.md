# 크레셀

AI 구독의 남는 사용량을 크레딧으로 팔고, 한도에 걸린 사람은 필요한 만큼만 사서 바로 이어 쓰는 앱입니다. 콘텐츠서비스디자인 기말 과제용 시연 프로토타입이며, 실제 결제나 거래는 일어나지 않습니다.

## 바로 보기

- 앱: https://banghozin.github.io/app/
- 전체 흐름도(화면 61개와 연결선 한 화면): https://banghozin.github.io/app/?board=all

## 기기별로 보이는 모습

- 휴대폰과 태블릿에서 열면 폰 모양 테두리 없이 화면 전체가 실제 앱처럼 움직입니다.
- PC에서 열면 왼쪽에 화면 목록, 가운데에 폰 모양으로 보입니다. 휴대폰에서도 폰 모양으로 보고 싶으면 주소 끝에 `?frame=1`을 붙입니다.

## 앱으로 설치하기

1. 휴대폰이나 태블릿의 크롬에서 위 앱 주소를 엽니다.
2. 오른쪽 위 메뉴에서 "홈 화면에 추가" 또는 "앱 설치"를 누릅니다.
3. 홈 화면의 크레셀 아이콘으로 열면 주소창 없이 앱처럼 열립니다. 한 번 연 뒤에는 인터넷이 없어도 열립니다.

아이폰은 사파리에서 공유 버튼, "홈 화면에 추가" 순서로 설치합니다.

## 구성

- 화면 61개, 9개 묶음(처음 들어오기, 바깥 접점, 홈, 사기, 평가, 팔기, 내역과 정산, 마이페이지, 고객센터)
- 휴대폰 뒤로가기와 화면 안 뒤로 버튼이 같은 규칙으로 움직입니다. 완료 화면에서 뒤로가기를 누르면 결제 화면으로 돌아가지 않고 홈이나 목록으로 갑니다.
- 전체 흐름도는 끌어서 이동하고 휠이나 두 손가락으로 확대합니다. 화면을 누르면 그 화면부터 시연합니다.
